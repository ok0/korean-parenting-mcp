# 키 없이 바로 쓰는 기능

> 공공기관이 제공하는 공개 API와 자료를 이용해 정리해 드려요. 최종 확인은 해당 기관에서 해 주세요. 의료·법률 자문이 아니며, 건강 상태는 의료진에게, 제도·신청 기한은 관할 기관에 확인하세요.

API 키 없이 설치 즉시 동작합니다. 아래 기능은 키를 설정하지 않아도 됩니다. 설치는 [설치 방법 고르기](install.md)를 보세요.

## 도구

| 도구 | 하는 일 | 상태 |
| --- | --- | --- |
| `get_timeline` | 출생일·출산 예정일 기준 임신·육아 일정 안내 | ✅ 확인됨(정적 데이터 계산, 공휴일 확인은 선택) |
| `find_daycare` | 어린이집 찾기·입소대기 링크 안내 | 🔗 링크 안내 |
| `find_vaccination_clinic` | 예방접종 위탁의료기관 찾기 링크 안내 | 🔗 링크 안내 |
| `find_checkup_clinic` | 영유아 건강검진 기관 찾기 안내 | ✅ 확인됨(키 없으면 링크 안내, 공공데이터포털 키가 있으면 기관 조회) |

✅ 확인됨: 실제 API 호출로 동작 확인 · ⏳ 키 승인 대기: 키 승인 전이라 실제 호출 미확인 · 🔗 링크 안내: 데이터를 조회하지 않고 공식 페이지 링크를 알려 줌

`get_timeline`은 번들 정적 데이터로 일정을 계산해 외부 호출이 없습니다. 공공데이터포털 키(`DATA_GO_KR_SERVICE_KEY`)가 있으면 공휴일을 실시간으로 확인하며, 이 확인은 실제 API 호출로 동작을 확인했습니다.

`find_checkup_clinic`은 키가 없으면 검진기관을 찾는 절차와 문의처를 링크로 안내합니다. 공공데이터포털 키(`DATA_GO_KR_SERVICE_KEY`)를 설정하고 사는 지역(시·군·구)을 알려 주면 영유아 건강검진·구강검진 기관의 이름·종별·주소·전화번호를 함께 보여 줍니다. 조회 결과에 나온 기관이라도 영유아·구강검진 실시 여부와 예약은 방문 전에 기관에 전화로 확인하세요. 시·도만 알려 주었거나 구 단위로 나뉜 시처럼 조회가 안 되는 지역, 또는 조회에 실패한 경우에는 링크 안내로 대신합니다.

## 사용 예

- "2026년 3월 15일에 출산했어. 앞으로 받을 예방접종과 검진 일정을 알려줘."
- "출산 예정일이 2027년 2월 10일이야. 지금 임신 중에 챙길 일정을 정리해줘."
- "육아휴직 기간과 관련해 필요한 일정을 날짜 순서로 보여줘."

API 키가 있으면 더 쓸 수 있는 기능은 [API 키로 기능 더하기(선택)](advanced.md)에 있습니다.
