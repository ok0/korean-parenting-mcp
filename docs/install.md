# 설치 방법 고르기

> 이 문서는 정부·공공기관과 관계없는 비공식 개인 프로젝트의 안내입니다. 의료·법률 자문이 아니며, 건강 상태는 의료진에게, 제도·신청 기한은 관할 기관에 확인하세요.

## 하나만 고르세요

| 내 상황 | 방법 |
| --- | --- |
| Claude 데스크톱 앱을 쓰고 터미널이 낯설다 | [Claude 데스크톱 앱에 설치하기(파일 하나로)](mcpb.md) |
| 터미널 명령 한 줄은 괜찮고 설정 마법사가 지원하는 앱(Claude 데스크톱 앱, Claude Code)을 쓴다 | [설정 마법사로 설치하기](setup-wizard.md) |
| 그 밖의 AI 앱(예: VS Code, Cursor 등) | [직접 설정하기(AI 앱별)](clients/README.md) |

여러 방법을 함께 쓰면 같은 서버가 두 번 등록될 수 있어요. 한 가지만 고르세요.

## 직접 설정할 때 필요한 정보

### 요구 사항

STDIO MCP 서버입니다. Node.js 20.19 이상이 필요합니다.

### 실행 명령

```bash
npx -y korean-parenting-mcp
```

API 키 없이 바로 실행됩니다. 키 없이 쓰는 기능은 [키 없이 바로 쓰는 기능](keyless.md)을 보세요.

MCP를 지원하는 AI 앱이면 이 명령을 STDIO 서버로 등록해 쓸 수 있습니다(예: Claude 데스크톱 앱, Claude Code, VS Code, Cursor 등). 앱마다 등록 방법이 다르니 [직접 설정하기(AI 앱별)](clients/README.md)나 각 앱의 MCP 설정 안내를 따르세요.

### API 키 넣기(선택)

키는 AI 앱의 MCP 설정에서 이 서버의 환경 변수로 넣거나 [설정 마법사로 설치하기](setup-wizard.md)로 넣습니다. 키 이름과 발급 방법은 [API 키로 기능 더하기(선택)](advanced.md)을 보세요.
