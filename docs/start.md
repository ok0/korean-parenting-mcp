# 처음이라면: 쉬운 시작 안내

> 공공기관이 제공하는 공개 API와 자료를 이용해 정리해 드려요. 최종 확인은 해당 기관에서 해 주세요. 의료·법률 자문이 아니며, 건강 상태는 의료진에게, 제도·신청 기한은 관할 기관에 확인하세요.

## 이게 뭔가요

AI 앱에 붙여 쓰는 한국 임신·출산·육아 일정 도우미예요.

MCP는 AI 앱이 바깥 도구를 불러 쓸 수 있게 해 주는 연결 방식이에요.

## 무엇이 필요한가요

AI 앱 하나만 있으면 돼요. API 키는 필요 없어요.

키가 있으면 기능을 더할 수 있어요. [API 키로 기능 더하기(선택)](advanced.md)에서 자세히 보세요.

## 설치 방법 하나 고르기

셋 중 하나만 고르면 돼요. 자세한 비교는 [설치 방법 고르기](install.md)에 있어요.

- [Claude 데스크톱 앱에 설치하기(파일 하나로)](mcpb.md) — Claude 데스크톱 앱을 쓰고 터미널이 낯설 때
- [설정 마법사로 설치하기](setup-wizard.md) — 터미널 명령 한 줄이 괜찮을 때
- [직접 설정하기(AI 앱별)](clients/README.md) — 그 밖의 AI 앱

## 가장 쉬운 길: Claude 데스크톱 앱

1. Claude 데스크톱 앱을 설치하고 로그인해 두세요.
2. 설치 파일을 내려받아 앱에서 여세요. 받는 방법은 [Claude 데스크톱 앱에 설치하기(파일 하나로)](mcpb.md)에 차근차근 나와 있어요.
3. 설치 화면에 API 키 입력 칸이 나오면 모두 비워 둬도 돼요.
4. 앱을 완전히 닫았다가 다시 여세요.

## 첫 질문 해 보기

- "출산 예정일이 2027년 3월 15일이야. 챙길 일정을 알려줘."
- "아이가 2026년 3월 15일에 태어났어. 예방접종 일정을 알려줘."

더 많은 예는 [키 없이 바로 쓰는 기능](keyless.md)에 있어요.
